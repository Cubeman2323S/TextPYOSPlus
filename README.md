# TextPYOSPlus

TextPYOS (the original Repository) is a project that is inspired by early command line operating systems (e.x. MS-DOS, Linux, ect) that seeks to give the same experience without being a full-fledged operating system.

TextPYOSPlus is intended to be **Python only.**

TextPYOSPlus is the extension to TextPYOS, which seeks to add QoL features.

## Licensing

TextPYOSPlus is open-source under the [MIT License](LICENSE).

## Installation

TextPYOSPlus works best with an IDE. Installation via Pyinstaller (like the original suggested) is unadvised, as it has (in the past) led to false red flags about malware.

## Updates

TextPYOSPlus is a hobby extension of the original TextPYOS. Updates are likely to be small and infrequent.

Large updates that add entirely new features rather than expanding on existing ones are possible, but should not be expected.
